## 1. Veredito

O app funciona, mas **nenhum endpoint tem contrato**: das 43 edge functions, nenhuma usa Zod, só uma devolve
422, há sete formatos de erro diferentes e os "testes de contrato" existentes validam schemas inventados dentro
do próprio teste. No front, a validação de formulário é praticamente inexistente (um `useForm`, zero
`zodResolver`), a acessibilidade está abaixo do mínimo (≈93 botões sem nome, 443 campos sem label) e há
quatro falhas de segurança abertas (senha em claro para a edge, assistente de IA com `Bearer undefined`,
webhooks com HMAC fail‑open ou validado depois do contrato, e funções acionáveis com a anon key).

## 3. Sugestões de correção (forma final dos contratos)

Formato único de erro de validação (todas as funções, todas as versões):

```ts
// supabase/functions/_shared/contracts/errors.ts
export const ContractErrorSchema = z.object({
  code: z.enum([
    "VALIDATION_FAILED",
    "INVALID_JSON",
    "PAYLOAD_TOO_LARGE",
    "METHOD_NOT_ALLOWED",
    "UNSUPPORTED_VERSION",
    "UNAUTHORIZED",
    "FORBIDDEN",
    "NOT_FOUND",
    "CONFLICT",
    "RATE_LIMITED",
    "UPSTREAM_ERROR",
    "UPSTREAM_TIMEOUT",
    "INTERNAL_ERROR",
    "GONE",
  ]),
  message: z.string(),
  fields: z.array(
    z.object({ path: z.string(), code: z.string(), message: z.string() }),
  ),
  version: z.string(), // "v1" | "v2"
  requestId: z.string().optional(),
});
// 422 → { code: "VALIDATION_FAILED", message: "Payload inválido", fields: [{ path: "carrier_id", code: "invalid_type", message: "Expected string, received number" }], version: "v1" }
```

Parse com limite e wrapper:

```ts
// supabase/functions/_shared/contracts/parseBody.ts
export async function parseJsonBody<T>(
  req: Request,
  schema: z.ZodType<T>,
  maxBytes = 256_000,
) {
  const raw = await req.text();
  if (new TextEncoder().encode(raw).byteLength > maxBytes)
    throw contractError("PAYLOAD_TOO_LARGE");
  let json: unknown;
  try {
    json = JSON.parse(raw);
  } catch {
    throw contractError("INVALID_JSON");
  }
  const r = schema.safeParse(json);
  if (!r.success)
    throw contractError(
      "VALIDATION_FAILED",
      r.error.issues.map((i) => ({
        path: i.path.join("."),
        code: i.code,
        message: i.message,
      })),
    );
  return r.data;
}
// supabase/functions/carrier-webhook-receiver/index.ts
export const handler = withContract(
  { name: "carrier-webhook-receiver", versions: { v1, v2 }, default: "v1" },
  async (req, ctx) =>
    webhookGuard(
      req,
      ctx,
      { secret: "CARRIER_WEBHOOK_SECRET", schema: ctx.schema },
      process,
    ),
);
if (import.meta.main) Deno.serve(handler);
```

Negociação de versão: `X-Contract-Version: 2` (ou `?v=2` para parceiros que não controlam headers);
ausente = `v1`; `v1` em descontinuação responde `Deprecation: true` e `Sunset: <data>`; versão desconhecida
→ 400 `UNSUPPORTED_VERSION`; versão após o sunset → 410 `GONE`.

Teste de contrato mínimo por função (gerado a partir do schema, etapa 087):
